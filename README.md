# Stillpoint

A calm ritual app for the moment an urge hits. Open it, run the same ritual every time (spot, pose, headphones, breath, music, your own reminder lines) and let the habit carry you past the urge.

- **Modes:** one ritual per temptation, each with its own steps, lines and music.
- **Streaks:** clean days per rule; reset honestly when you slip, best streak is kept.
- **Urges:** a log of when urges hit, how they ended, and which mode.
- **Offline and private:** installable web app (PWA). All data stays on the phone; use Edit modes → Backup to save it.

Install on Android: open the GitHub Pages address in Chrome, then ⋮ → Install app.
